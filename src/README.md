# Mekakushi

A simple text masking application for macOS.

## 最終版: UI改善完了 - シンプルで直感的なインターフェース

このバージョンでは、ユーザーからの全ての要求に基づいて最終的なUI改善を実装しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/Mekakushi/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 最新の改善点 🚀

#### 薄い青色ハイライト機能（Query 14対応）🆕
- **視覚的識別**: 変換された文字列と変換元の文字列を薄い青色でハイライト表示
- **入力テキストエリア**: 辞書に登録された元の文字列（例: "password"）をハイライト
- **出力テキストエリア**: マスクされた文字列（例: "[SECRET]", "りんご"）をハイライト
- **リアルタイム更新**: マスキング辞書の変更に応じてハイライトも即座に更新
- **セキュリティ向上**: HTMLエスケープ処理を改善してXSS攻撃を防止

#### 最終UI改善（Query 13対応）
- **ステータス表示削除**: 「準備完了」などのステータス表示を完全に削除し、よりクリーンなUI
- **装飾的変換矢印**: ➡️⬅️を機能的なボタンから装飾的な要素に変更（グレー、控えめ）
- **シンプル化**: 不要な機能を削除し、コア機能に集中したインターフェース

#### 革新的なポップアップUI
- **マウス付近にポップアップ表示**: テキスト選択時に候補選択がマウスカーソル付近に表示
- **自動マスキング**: 候補をクリックするだけで即座にマスキング実行（ボタンクリック不要）
- **直感的な操作**: 選択→候補クリック→完了の簡単な3ステップ

#### リアルタイム同期システム
- **即座の反映**: 入力テキストの変更が瞬時に出力テキストに反映
- **自動辞書適用**: 過去にマスキングした単語は自動的に適用
- **シームレスな体験**: 入力と出力が常に同期された状態

#### 個別制御機能
- **個別削除**: 辞書の各項目に🗑️ボタンで細かい制御が可能
- **一括削除の廃止**: 「辞書をクリア」ボタンを削除し、誤操作を防止
- **精密な管理**: 必要な項目だけを残して不要な項目を削除

#### ミニマルデザイン
- **タイトル削除**: 「Mekakushi」タイトルを削除してスペース効率化
- **外枠削除**: 四角い外枠を削除してモダンでクリーンな見た目
- **ステータス削除**: 不要なステータス表示を削除してスッキリ
- **装飾的矢印**: 機能的なボタンから視覚的な流れを示す装飾に変更
- **集中できるUI**: 機能に集中できるシンプルなインターフェース

### 使用方法

#### 新しいマスキング手順（超簡単！）
1. 左のテキストエリアでマスキングしたい部分を**選択**
2. マウス付近に表示されるポップアップで**カテゴリを選択**（🔤記号・文字、🍎果物、🐱動物、⭐星、🎨色、🌍国）
3. 候補グリッドから希望の候補を**クリック**
4. **完了！** 選択した部分が即座にマスキングされ、辞書に記録される

#### カテゴリと候補
- **🔤 記号・文字**: *, X, #, ●, ■, [MASK], [SECRET], ***, XXX など30種類
- **🍎 果物**: りんご、みかん、バナナ、いちご、ぶどう、もも、なし など18種類
- **🐱 動物**: ねこ、いぬ、うさぎ、ハムスター、とり、さかな、ぞう など20種類
- **⭐ 星**: シリウス、カノープス、アルクトゥルス、ベガ、カペラ など20種類
- **🎨 色**: あか、あお、きいろ、みどり、むらさき、オレンジ など18種類
- **🌍 国**: にほん、アメリカ、イギリス、フランス、ドイツ など18種類

#### リアルタイム機能
1. **入力と同時に反映**: 入力テキストを変更すると即座に出力テキストに反映
2. **自動辞書適用**: 過去にマスキングした単語は自動的に適用される
3. **個別削除**: 辞書の各項目の🗑️ボタンで不要な項目を削除

#### その他の機能
- **📋 個別コピー**: 各テキストエリアの右下コピーボタンでクリップボードにコピー
- **➡️⬅️ 装飾的矢印**: 視覚的な変換の流れを示す装飾要素（機能なし）
- **💙 ハイライト表示**: 変換された文字列を薄い青色でハイライト表示し、視覚的に識別可能
- **Escキー**: ポップアップが表示されている時にEscキーで閉じる
