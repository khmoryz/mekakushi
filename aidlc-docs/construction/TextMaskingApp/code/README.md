# Text Masking App

## ステップ4: 手動選択マスキング

このステップでは、ユーザーが選択したテキストをマスキングする機能を実装しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/TextMaskingApp/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 現在の機能

- ✅ Electronウィンドウが起動
- ✅ デュアルパネルレイアウト（左：入力、右：マスキング済み出力）
- ✅ **自動マスキング機能**
  - `password` → `****`
  - `secret` → `***`
  - `confidential` → `****`
  - `private` → `***`
  - `admin` → `***`
  - `root` → `***`
- ✅ **手動選択マスキング機能** 🆕
  - テキスト選択の検出
  - 選択されたテキストを`***`に置換
  - 選択部分の長さに応じたマスク調整
  - 動的ボタンラベル更新
- ✅ クリップボードコピー機能
- ✅ ステータス表示とフィードバック
- ✅ キーボードショートカット（Ctrl/Cmd + Enter）

### 完成状態

テキストを選択してボタンを押すと、選択部分がマスクされるアプリケーション

### 使用方法

#### 自動マスキング
1. 左のテキストエリアにテキストを入力
2. 「🔒 自動マスキング」ボタンをクリック
3. 事前定義された単語が自動的にマスクされる

#### 手動選択マスキング
1. 左のテキストエリアでマスキングしたい部分を選択
2. 「✂️ 選択部分をマスク」ボタンをクリック（選択時に有効化）
3. 選択した部分が`***`に置換される
