# Text Masking App

## ステップ6+改良版: UI構造改善 - 候補選択統一

このステップでは、ユーザーからの改善要求に基づいてUI構造を大幅に改善しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/TextMaskingApp/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 現在の機能

- ✅ Electronウィンドウが起動
- ✅ デュアルパネルレイアウト（左：入力、右：マスキング済み出力）
- ✅ **手動選択マスキング機能**（メイン機能）
  - テキスト選択の検出
  - 選択されたテキストを選択候補に置換
  - 選択部分の長さに応じたマスク調整
  - 動的ボタンラベル更新
- ✅ **統一された候補選択機能** 🆕
  - **6つのカテゴリ**: 🔤記号・文字、🍎果物、🐱動物、⭐星、🎨色、🌍国
  - **約50個の候補**: 記号・文字カテゴリに30個、その他各カテゴリに10-20個の候補
  - **視覚的選択**: グリッド表示で候補をクリック選択
  - **選択状態表示**: 選択された候補をハイライト表示
  - **記号・文字がデフォルト**: アプリ起動時は記号・文字カテゴリが選択済み
- ✅ **基本的な辞書機能**
  - メモリ内辞書（Map）
  - 同じ文字列の自動マスキング
  - 辞書の表示（簡単なリスト）
  - 使用回数と最終使用日時の記録
  - 辞書のクリア機能
  - 最近使用順でのソート表示
- ✅ クリップボードコピー機能
- ✅ ステータス表示とフィードバック
- ✅ キーボードショートカット（Ctrl/Cmd + Enter）

### 改善された点 �

#### UI構造の簡素化
- **モード切り替えを廃止**: 「記号・文字」と「候補選択」の2つのモードを統一
- **記号・文字をカテゴリ化**: 独立したモードから候補選択内の一カテゴリに変更
- **シンプルなワークフロー**: カテゴリ選択 → 候補選択 → マスキング実行

#### 機能の整理
- **自動マスキング機能を削除**: 複雑さを減らし、手動選択マスキングに集中
- **不要なUI要素を削除**: マスク文字入力フィールドやプリセットボタンを削除
- **一貫したインターフェース**: すべてのマスキングが同じ候補選択方式

#### ユーザビリティの向上
- **直感的な操作**: カテゴリ → 候補 → マスキングの明確なフロー
- **デフォルト設定**: 記号・文字カテゴリが最初に選択されているため、従来の使い方も可能
- **視覚的フィードバック**: 選択状態とステータスメッセージの改善

### 完成状態

シンプルで直感的な候補選択方式により、手動選択マスキングに特化したアプリケーション

### 使用方法

#### 基本的なマスキング手順
1. 左のテキストエリアでマスキングしたい部分を選択
2. カテゴリボタン（🔤記号・文字、🍎果物、🐱動物、⭐星、🎨色、🌍国）から選択
3. 表示された候補グリッドから希望の候補をクリック
4. 「✂️ 選択部分をマスク」ボタンをクリック（選択時に有効化）
5. 選択した部分が選択されたマスク候補で置換される

#### カテゴリと候補
- **🔤 記号・文字**: *, X, #, ●, ■, [MASK], [SECRET], ***, XXX など30種類
- **🍎 果物**: りんご、みかん、バナナ、いちご、ぶどう、もも、なし など18種類
- **🐱 動物**: ねこ、いぬ、うさぎ、ハムスター、とり、さかな、ぞう など20種類
- **⭐ 星**: シリウス、カノープス、アルクトゥルス、ベガ、カペラ など20種類
- **🎨 色**: あか、あお、きいろ、みどり、むらさき、オレンジ など18種類
- **🌍 国**: にほん、アメリカ、イギリス、フランス、ドイツ など18種類

#### 辞書機能
1. マスキングした単語は自動的に辞書に記録される
2. 「📚 マスキング辞書」セクションで履歴を確認
3. 同じ単語は次回自動的にマスキングされる
4. 「🗑️ 辞書をクリア」ボタンで履歴をリセット
