1. **依存関係のインストール**

2. **アプリケーションの起動**

### 大幅に改善された点 🚀

#### 革新的なポップアップUI
- **マウス付近にポップアップ表示**: テキスト選択時に候補選択がマウスカーソル付近に表示

#### リアルタイム同期システム
- **即座の反映**: 入力テキストの変更が瞬時に出力テキストに反映

- **精密な管理**: 必要な項目だけを残して不要な項目を削除

#### ミニマルデザイン
- **タイトル削除**: 「Text Masking App」タイトルを削除してスペース効率化
- **外枠削除**: 四角い外枠を削除してモダンでクリーンな見た目

### 使用方法

#### 新しいマスキング手順（超簡単！）
1. 左のテキストエリアでマスキングしたい部分を**選択**
2. マウス付近に表示されるポップアップで**カテゴリを選択**（🔤記号・文字、🍎果物、🐱動物、⭐星、🎨色、🌍国）
3. 候補グリッドから希望の候補を**クリック**
4. **完了！** 選択した部分が即座にマスキングされ、辞書に記録される

#### カテゴリと候補
- **🔤 記号・文字**: *, X, #, ●, ■, [MASK], [SECRET], ***, XXX など30種類
- **🍎 果物**: りんご、みかん、バナナ、いちご、ぶどう、もも、なし など18種類
- **🐱 動物**: ねこ、いぬ、うさぎ、ハムスター、とり、さかな、ぞう など20種類
- **⭐ 星**: シリウス、カノープス、アルクトゥルス、ベガ、カペラ など20種類
- **🎨 色**: あか、あお、きいろ、みどり、むらさき、オレンジ など18種類
- **🌍 国**: にほん、アメリカ、イギリス、フランス、ドイツ など18種類

#### リアルタイム機能
1. **入力と同時に反映**: 入力テキストを変更すると即座に出力テキストに反映
2. **自動辞書適用**: 過去にマスキングした単語は自動的に適用される
3. **個別削除**: 辞書の各項目の🗑️ボタンで不要な項目を削除

#### その他の機能
- **📋 テキストをコピー**: マスキング済みテキストをクリップボードにコピー
- **Escキー**: ポップアップが表示されている時にEscキーで閉じる
