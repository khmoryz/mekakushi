# Text Masking App

## ステップ3: 最も単純なマスキング機能

このステップでは、固定文字列を固定マスクに置換する基本的なマスキング機能を実装しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/TextMaskingApp/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 現在の機能

- ✅ Electronウィンドウが起動
- ✅ デュアルパネルレイアウト（左：入力、右：マスキング済み出力）
- ✅ 固定文字列マスキング機能
  - `password` → `****`
  - `secret` → `***`
  - `confidential` → `****`
  - `private` → `***`
  - `admin` → `***`
  - `root` → `***`
- ✅ マスキング実行ボタン
- ✅ クリップボードコピー機能
- ✅ ステータス表示とフィードバック
- ✅ キーボードショートカット（Ctrl/Cmd + Enter）

### 完成状態

特定の単語（例: "password"）を"****"に置換するマスキング機能を持つアプリケーション

### 使用方法

1. 左のテキストエリアにテキストを入力
2. 「🔒 テキストをマスキング」ボタンをクリック
3. 右のテキストエリアにマスキング結果が表示
4. 「📋 テキストをコピー」でクリップボードにコピー
