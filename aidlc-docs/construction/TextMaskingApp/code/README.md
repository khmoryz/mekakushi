# Text Masking App

## ステップ2: 基本的なテキスト表示アプリ

このステップでは、左右2つのテキストエリアが表示され、左に入力したテキストが右に表示される機能を実装しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/TextMaskingApp/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 現在の機能

- ✅ Electronウィンドウが起動
- ✅ デュアルパネルレイアウト（左：入力、右：出力）
- ✅ リアルタイムテキスト同期（左に入力すると右に表示）
- ✅ テキストコピーボタン
- ✅ macOSネイティブウィンドウ動作

### 完成状態

左のテキストエリアに入力すると、右に同じテキストが表示される動作するアプリケーション
