# Text Masking App

## ステップ6+: 候補選択機能付き基本的な辞書機能

このステップでは、一度マスキングした文字列を記憶する辞書機能に加えて、候補選択機能を実装しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/TextMaskingApp/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 完成状態

マスク文字と候補選択の両方のモードを持ち、一度マスキングした文字列は次回自動的にマスキングされるアプリケーション

### 使用方法

#### マスクモード切り替え
1. 「🎭 マスク設定」セクションで「記号・文字」または「候補選択」を選択
2. **記号・文字モード**: 従来のマスク文字（*, X, #など）を使用
3. **候補選択モード**: 事前定義された候補（果物、動物、星など）から選択

#### 候補選択モード
1. 「候補選択」モードを選択
2. カテゴリボタン（🍎果物、🐱動物、⭐星、🎨色、🌍国）から選択
3. 表示された候補グリッドから希望の候補をクリック
4. 選択された候補がマスキングに使用される

#### 自動マスキング
1. 左のテキストエリアにテキストを入力
2. マスクモードと候補（候補選択モードの場合）を選択
3. 「🔒 自動マスキング」ボタンをクリック
4. 事前定義された単語が選択されたマスク方法で置換される

#### 手動選択マスキング
1. 左のテキストエリアでマスキングしたい部分を選択
2. マスクモードと候補（候補選択モードの場合）を選択
3. 「✂️ 選択部分をマスク」ボタンをクリック（選択時に有効化）
4. 選択した部分が選択されたマスク方法で置換される

#### 辞書機能
1. マスキングした単語は自動的に辞書に記録される
2. 「📚 マスキング辞書」セクションで履歴を確認
3. 同じ単語は次回自動的にマスキングされる
4. 「🗑️ 辞書をクリア」ボタンで履歴をリセット

- **🐱 動物**: ねこ、いぬ、うさぎ、ハムスター、とり、さかな、ぞう、きりん、らいおん、とら など
- **⭐ 星**: シリウス、カノープス、アルクトゥルス、ベガ、カペラ、リゲル、プロキオン など
- **🎨 色**: あか、あお、きいろ、みどり、むらさき、オレンジ、ピンク、ちゃいろ など
- **🌍 国**: にほん、アメリカ、イギリス、フランス、ドイツ、イタリア、スペイン など
