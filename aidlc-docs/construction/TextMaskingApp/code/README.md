# Text Masking App

## ステップ5: カスタムマスク文字

このステップでは、マスク文字を変更可能にする機能を実装しました。

### セットアップ手順

1. **依存関係のインストール**
   ```bash
   cd aidlc-docs/construction/TextMaskingApp/code
   npm install
   ```

2. **アプリケーションの起動**
   ```bash
   npm start
   ```

### 現在の機能

- ✅ Electronウィンドウが起動
- ✅ デュアルパネルレイアウト（左：入力、右：マスキング済み出力）
- ✅ **自動マスキング機能**
  - `password` → カスタムマスク文字
  - `secret` → カスタムマスク文字
  - `confidential` → カスタムマスク文字
  - `private` → カスタムマスク文字
  - `admin` → カスタムマスク文字
  - `root` → カスタムマスク文字
- ✅ **手動選択マスキング機能**
  - テキスト選択の検出
  - 選択されたテキストをカスタムマスク文字に置換
  - 選択部分の長さに応じたマスク調整
  - 動的ボタンラベル更新
- ✅ **カスタムマスク文字機能** 🆕
  - マスク文字入力フィールド
  - プリセットボタン（*, X, #, [MASK], ●）
  - マスク文字の動的変更
  - 設定の保持（メモリ内）
  - 長さに応じた動的マスク生成
- ✅ クリップボードコピー機能
- ✅ ステータス表示とフィードバック
- ✅ キーボードショートカット（Ctrl/Cmd + Enter）

### 完成状態

マスク文字を"*"から"X"や"[MASK]"に変更できるアプリケーション

### 使用方法

#### 自動マスキング
1. 左のテキストエリアにテキストを入力
2. 「🔒 自動マスキング」ボタンをクリック
3. 事前定義された単語がカスタムマスク文字でマスクされる

#### 手動選択マスキング
1. 左のテキストエリアでマスキングしたい部分を選択
2. 「✂️ 選択部分をマスク」ボタンをクリック（選択時に有効化）
3. 選択した部分がカスタムマスク文字に置換される

#### カスタムマスク文字設定
1. 「🎭 マスク設定」セクションでマスク文字を変更
2. 入力フィールドに直接入力するか、プリセットボタンを使用
3. 設定は即座に反映され、メモリ内に保持される
