# Mekakushi コード生成計画

## ユニットコンテキスト

### ユニット情報
- **ユニット名**: Mekakushi
- **ユニットタイプ**: 統合デスクトップアプリケーション（Electron）
- **技術スタック**: Electron + React + TypeScript + Node.js

### 実装するストーリー
- エピック1: テキスト入力とクリップボード統合
- エピック2: 手動テキスト選択マスキング
- エピック3: パターンベースマスキング
- エピック4: 辞書管理
- エピック5: 出力とクリップボード統合
- エピック6: カスタムマスキング形式
- エピック7: エラーハンドリングとエッジケース

### アーキテクチャ構成
```
Mekakushi
├── メインプロセス (Node.js + TypeScript)
│   ├── MaskingEngine - 統合マスキング処理
│   ├── Dictionary - 辞書データ管理
│   └── FileManager - ファイル操作
└── レンダラープロセス (React + TypeScript)
    ├── App - アプリケーション状態管理
    ├── InputPanel - テキスト入力
    ├── OutputPanel - 結果表示
    ├── Controls - マスキング制御
    └── DictionaryPanel - 辞書管理
```
