# 設計仕様書 - Mekakushi

## 概要

Mekakushiは、機密情報を効率的にマスキングするためのmacOSネイティブアプリケーションです。Electronベースで構築され、プロジェクト環境管理、双方向テキスト処理、永続的マスキング辞書を提供します。

## アーキテクチャ

### システム構成
```
┌─────────────────────────────────────────┐
│              Frontend (HTML/CSS/JS)     │
├─────────────────────────────────────────┤
│              Electron Main Process      │
├─────────────────────────────────────────┤
│              File System (JSON)         │
└─────────────────────────────────────────┘
```


## コンポーネント設計

### 1. ProjectManager
**責任**: プロジェクト環境の作成、切り替え、削除
- `createProject(name)`: 新しいプロジェクト環境を作成
- `switchProject(projectId)`: プロジェクト環境を切り替え
- `deleteProject(projectId)`: プロジェクト環境を削除
- `listProjects()`: 全プロジェクト環境を取得

### 2. MaskingEngine
**責任**: テキストのマスキング・アンマスキング処理
- `maskText(text, dictionary)`: テキストをマスキング
- `unmaskText(text, dictionary)`: テキストをアンマスキング
- `detectMaskableText(text, dictionary)`: マスキング可能なテキストを検出

### 3. DictionaryManager
**責任**: マスキング辞書の管理
- `loadDictionary(projectId)`: プロジェクトの辞書を読み込み
- `saveDictionary(projectId, dictionary)`: 辞書を保存
- `addEntry(original, masked)`: 新しいマスキングルールを追加
- `removeEntry(original)`: マスキングルールを削除

### 4. UIController
**責任**: ユーザーインターフェースの制御
- `updateTextPanels()`: テキストパネルの更新
- `showProjectSelector()`: プロジェクト選択UIの表示
- `handleTextSelection()`: テキスト選択の処理

## 正確性プロパティ

*プロパティとは、システムのすべての有効な実行において真であるべき特性や動作です。これらは人間が読める仕様と機械で検証可能な正確性保証の橋渡しとなります。*

### プロパティ1: プロジェクト環境の独立性
*すべての*プロジェクト環境において、あるプロジェクトのマスキング辞書は他のプロジェクトのマスキング辞書と完全に独立している
**検証: 要求事項1.1, 1.2**

### プロパティ2: マスキングの一貫性
*すべての*テキストとマスキング辞書において、同じ元テキストは常に同じマスキング結果を生成する
**検証: 要求事項3.2, 5.3**

### プロパティ3: ラウンドトリップ整合性
*すべての*有効なマスキング辞書において、マスキング→アンマスキングの操作は元のテキストを復元する
**検証: 要求事項7.2, 8.4**

### プロパティ4: データ永続性
*すべての*マスキングルール作成において、ルールはアプリケーション再起動後も保持される
**検証: 要求事項6.1, 6.2**

### プロパティ5: UI同期性
*すべての*テキスト変更において、ソースパネルとターゲットパネルは即座に同期される
**検証: 要求事項3.3, 8.3**

## エラーハンドリング

### ファイルシステムエラー
- プロジェクトファイルの読み書きエラー
- 辞書ファイルの破損
- ディスク容量不足

### データ整合性エラー
- 循環マスキングルール
- 競合するマスキングルール
- 不正なプロジェクトID

### UI エラー
- 大容量テキストの処理
- 無効なテキスト選択
- クリップボードアクセスエラー
