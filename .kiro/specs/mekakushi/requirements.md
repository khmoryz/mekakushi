# 要求仕様書 - Mekakushi

## はじめに

Mekakushiは、ユーザーがAIシステムや外部サービスにテキストを共有する前に、機密情報を効率的にマスキングするためのmacOSユーティリティアプリケーションです。直感的なGUIでテキスト変換を行い、永続的なマスキングルールを提供します。

アプリケーション名「Mekakushi」は、AI（人工知能）とMask（マスキング）を組み合わせ、さらにEye Mask（アイマスク）の意味も込めて、機密情報を「見えなくする」機能を表現しています。

## 用語集

- **マスキング**: 機密テキストを代替表現に置き換えるプロセス
- **マスキング辞書**: 元のテキストとマスク後のテキストのマッピングを永続的に保存するコレクション
- **ソースパネル**: ユーザーが元のテキストを入力する左パネル
- **ターゲットパネル**: マスク後のテキストを表示する右パネル
- **マスキングルール**: 元のテキストとマスク後のテキストの対応関係
- **プロジェクト環境**: 独立したマスキング辞書を持つ作業環境

## 要求事項

### 要求事項1: プロジェクト環境管理

**ユーザーストーリー:** プロジェクト管理者として、異なるプロジェクト用に独立したマスキング辞書を管理したいので、プロジェクト間でのデータ混在を防ぎたい。

#### 受け入れ基準

1. ユーザーが新しいプロジェクト環境を作成するとき、システムは独立したマスキング辞書を生成すること
2. ユーザーがプロジェクト環境を切り替えるとき、システムは対応するマスキング辞書を読み込むこと
3. システムは現在アクティブなプロジェクト環境を明確に表示すること
4. ユーザーがプロジェクト環境を削除するとき、システムは確認を求めてから削除すること
5. システムは各プロジェクト環境の名前、作成日、最終更新日を管理すること

### 要求事項2: テキスト入力と表示

**ユーザーストーリー:** ユーザーとして、クリップボード経由でテキストを入力し、きれいなインターフェースで表示したいので、マスキング作業の準備ができる。

#### 受け入れ基準

1. ユーザーがクリップボードからソースパネルにテキストを貼り付けるとき、システムは編集可能なテキストエリアにテキストを表示すること
2. システムはパフォーマンス低下なしに最大10MBのテキスト入力をサポートすること
3. テキストが貼り付けられるとき、システムは元の書式と改行を保持すること
4. システムは大きなテキストブロックの貼り付け操作中に視覚的フィードバックを提供すること
5. システムは絵文字や特殊文字を含むUnicodeテキストを正しく処理すること

### 要求事項3: テキスト選択とマスキング

**ユーザーストーリー:** ユーザーとして、テキストを選択してマスキング変換を適用したいので、機密情報を保護できる。

#### 受け入れ基準

1. ユーザーがソースパネルでテキストを選択するとき、システムは選択されたテキストを明確にハイライト表示すること
2. ユーザーが選択されたテキストにマスキングを適用するとき、システムは文書全体の同じテキストのすべてのインスタンスを置換すること
3. テキストがマスキングされるとき、システムは即座にターゲットパネルを変換されたテキストで更新すること
4. システムはバッチマスキング操作のために複数の同時テキスト選択をサポートすること
5. ユーザーがテキストをマスキングするとき、システムは将来の使用のためにマッピングをマスキング辞書に保存すること

### 要求事項4: マスキング方法

**ユーザーストーリー:** ユーザーとして、マスキングするテキストを指定する複数の方法が欲しいので、異なるタイプの機密データを効率的に処理できる。

#### 受け入れ基準

1. ユーザーがテキストを手動で選択するとき、システムは選択範囲のマスキングオプションを提供すること
2. ユーザーが正規表現パターンを入力するとき、システムはマッチするすべてのテキストを識別してマスキングすること
3. ユーザーが事前定義カテゴリ（メール、電話など）を選択するとき、システムは自動的にマッチするパターンを検出してマスキングすること
4. ユーザーがカスタムマスキングルールを作成するとき、システムは手動辞書入力と編集を許可すること
5. システムは単一文書内で複数のマスキング方法の組み合わせをサポートすること

### 要求事項5: 柔軟なマスキング形式

**ユーザーストーリー:** ユーザーとして、マスキングされたテキストの表示方法をカスタマイズしたいので、機密データを保護しながら文書の可読性を維持できる。

#### 受け入れ基準

1. ユーザーがテキストをマスキングするとき、システムはカスタム置換テキストの指定を許可すること
2. システムは固定文字列、プレースホルダー、匿名化代替語を含む様々なマスキング形式をサポートすること
3. マスキング形式が適用されるとき、システムは同じ元テキストのすべてのインスタンスで一貫性を維持すること
4. システムはユーザーが指定したときにテキスト長の関係を保持すること
5. システムは置換テキストが偶然機密情報を露出しないことを検証すること

### 要求事項6: 永続的マスキング辞書

**ユーザーストーリー:** ユーザーとして、マスキングルールをセッション間で記憶してほしいので、一般的な変換を再作成する必要がない。

#### 受け入れ基準

1. ユーザーがマスキングルールを作成するとき、システムは自動的にローカルストレージに保存すること
2. アプリケーションが開始するとき、システムは以前に保存されたマスキングルールを読み込むこと
3. ユーザーが以前にマスキングされたテキストに遭遇するとき、システムは自動的に保存された変換を適用すること
4. システムはユーザーが保存されたマスキングルールを表示、編集、削除することを許可すること
5. システムは簡単さのためにマスキング辞書を暗号化されていないローカルファイルに保存すること

### 要求事項7: 逆変換（アンマスキング）

**ユーザーストーリー:** ユーザーとして、マスキングされたテキストを元のコンテンツに戻したいので、AI生成の回答で実際の名前と情報を復元できる。

#### 受け入れ基準

1. ユーザーがマスキングされたコンテンツを含むテキストをソースパネルに貼り付けるとき、システムは自動的にマスキング可能なテキストを検出してハイライト表示すること
2. ユーザーが逆変換を適用するとき、システムは保存された辞書を使用してマスキングされたテキストのすべてのインスタンスを元の値に置換すること
3. システムは同一セッション内で順方向マスキングと逆アンマスキング操作の両方をサポートすること
4. 逆変換を実行するとき、システムは現在のマスキング辞書に存在するテキストのみをアンマスキングすること
5. システムはアンマスキング可能なテキストと未知のマスキングされたテキストの明確な視覚的表示を提供すること

### 要求事項8: 双方向テキスト処理

**ユーザーストーリー:** ユーザーとして、マスキングとアンマスキングモードをシームレスに切り替えたいので、AI回答と元文書を効率的に処理できる。

#### 受け入れ基準

1. システムはマスキング対アンマスキング操作のトグルまたはモードセレクターを提供すること
2. アンマスキングモードのとき、システムは貼り付けられたテキストに対して自動的に逆変換を試行すること
3. モードを切り替えるとき、システムは現在のテキストコンテンツを保持し、適切な変換を適用すること
4. システムはラウンドトリップ一貫性をサポートすること：元→マスキング→アンマスキングは元と等しくなること
5. システムは一部のマスキングされたテキストが逆変換できない場合に部分マッチを適切に処理すること

### 要求事項9: 出力とエクスポート

**ユーザーストーリー:** ユーザーとして、マスキングされたテキストを他のアプリケーションで使用するために簡単にコピーしたいので、サニタイズされたコンテンツを安全に共有できる。

#### 受け入れ基準

1. ユーザーがマスキングされたテキストのコピーを要求するとき、システムはコンテンツをシステムクリップボードにコピーすること
2. システムは明確な「クリップボードにコピー」ボタンまたはキーボードショートカットを提供すること
3. テキストがコピーされるとき、システムはコピー操作の視覚的確認を提供すること
4. システムはターゲットアプリケーションとの互換性を確保するためにプレーンテキスト形式でテキストをコピーすること
5. システムはコピー操作中に大きなテキストブロックを効率的に処理すること

### 要求事項10: ユーザーインターフェース設計

**ユーザーストーリー:** ユーザーとして、シンプルで直感的なインターフェースが欲しいので、複雑なコントロールを学習することなくマスキングタスクに集中できる。

#### 受け入れ基準

1. システムは2つのメインパネルを表示すること：ソーステキスト（左）とマスキングされたテキスト（右）
2. システムは元のテキストとマスキングされたテキストの明確な視覚的区別を提供すること
3. インターフェースが読み込まれるとき、システムは基本的な使用に訓練を必要としない直感的なレイアウトを提示すること
4. システムはネイティブなルックアンドフィールのためにmacOSヒューマンインターフェースガイドラインに従うこと
5. システムは異なる画面サイズでうまく動作するレスポンシブレイアウトを提供すること

### 要求事項11: パフォーマンスと信頼性

**ユーザーストーリー:** ユーザーとして、アプリケーションがテキスト処理を迅速かつ確実に処理してほしいので、マスキングがワークフローを遅くしない。

#### 受け入れ基準

1. 最大1MBのテキストを処理するとき、システムは1秒以内にマスキング操作を完了すること
2. 最大10MBのテキストを処理するとき、システムは5秒以内にマスキング操作を完了すること
3. システムはすべての処理操作中にレスポンシブなUIを維持すること
4. エラーが発生するとき、システムは明確なエラーメッセージと回復オプションを提供すること
5. システムはクラッシュやデータ損失なしにエッジケースを適切に処理すること

### 要求事項12: セキュリティとプライバシー

**ユーザーストーリー:** ユーザーとして、機密データが安全でプライベートに保たれてほしいので、機密情報をアプリケーションに信頼して預けることができる。

#### 受け入れ基準

1. システムはネットワーク通信なしにすべてのテキストをローカルで処理すること
2. システはユーザー制御のマスキング辞書を超えて機密テキストコンテンツをログまたは保存しないこと
3. アプリケーションが閉じるとき、システムはメモリからすべての一時テキストをクリアすること
4. システムは外部サービスにテレメトリーや使用データを送信しないこと
5. システムはすべての処理がローカルで実行されることの明確な表示を提供すること

### 要求事項13: マスキングルール管理

**ユーザーストーリー:** ユーザーとして、マスキングルールを効果的に管理したいので、データ変換の制御を維持できる。

#### 受け入れ基準

1. システムは元のテキストとマスキングされたテキストのペアを含むすべての保存されたマスキングルールのビューを提供すること
2. ユーザーがマスキングルールを編集するとき、システムは現在の文書内のすべての影響を受けるテキストを更新すること
3. ユーザーがマスキングルールを削除するとき、システムは削除前に確認を求めること
4. システムはバックアップ目的でマスキング辞書のエクスポートとインポートを許可すること
5. システムは循環または競合するマスキングルールの作成を防止すること
