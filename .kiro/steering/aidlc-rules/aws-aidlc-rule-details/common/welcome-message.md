# 👋 AI-DLC (AI駆動開発ライフサイクル) へようこそ！ 👋

私は、あなたの特定のニーズに合わせてインテリジェントに調整される、適応型のソフトウェア開発ワークフローをご案内します。

## AI-DLCとは？

AI-DLCは、プロジェクトのニーズに適応する、構造化されつつも柔軟なソフトウェア開発プロセスです。経験豊富なソフトウェアアーキテクトが以下を行うようなものだと考えてください：
- **あなたの要件を分析し**、必要に応じて明確化のための質問をします
- 複雑さとリスクに基づいて**最適なアプローチを計画します**
- 単純な変更では**不要なステップをスキップ**し、複雑なプロジェクトでは包括的なカバレッジを提供します
- **すべてを文書化する**ので、決定と根拠の完全な記録が残ります
- 明確なチェックポイントと承認ゲートで**各フェーズを案内します**

### フェーズの内訳:

**INCEPTIONフェーズ** - *計画とアプリケーション設計*
- **目的**: 何を、なぜ構築するかを決定します
- **活動**: 要件の理解、既存コードの分析（もしあれば）、アプローチの計画
- **成果物**: 明確な要件、実行計画、並行開発のための作業単位数の決定
- **あなたの役割**: 質問に答える、計画をレビューする、方向性を承認する

**CONSTRUCTIONフェーズ** - *詳細設計、実装、テスト*
- **目的**: どのように構築するかを決定します
- **活動**: 詳細設計（必要な場合）、コード生成、包括的なテスト
- **成果物**: 動作するコード、テスト、ビルド手順
- **あなたの役割**: 設計をレビューする、実装計画を承認する、結果を検証する

**OPERATIONSフェーズ** - *デプロイと監視（将来）*
- **目的**: どのようにデプロイし、実行するか
- **ステータス**: 将来のデプロイと監視ワークフローのためのプレースホルダー
- **現在の状態**: ビルドとテスト活動はCONSTRUCTIONフェーズで処理されます

## 主要原則:

- ⚡ **完全適応型**: 各ステージはあなたのニーズに基づいて独立して評価されます
- 🎯 **効率的**: 単純な変更は本質的なステージのみを実行します
- 📋 **包括的**: 複雑な変更はすべての安全策を講じて完全な処理を受けます
- 🔍 **透明性**: 作業開始前に実行計画を確認し、承認します
- 📝 **文書化**: すべての決定と変更の完全な監査証跡
- 🎛️ **ユーザーコントロール**: ステージを含めるか除外するかをリクエストできます

## 次に何が起こるか:

1. **あなたのワークスペースを分析し**、これが新規プロジェクトか既存プロジェクトかを理解します
2. **要件を収集し**、必要に応じて明確化のための質問をします
3. **実行計画を作成し**、どのステージをなぜ実行するかの提案を示します
4. **あなたが計画をレビューし、承認します**（または変更をリクエストします）
5. **各主要ステージでチェックポイントを設けながら**、計画を実行します
6. **完全なドキュメントとテスト付きの**動作するコードを受け取ります

AI-DLCプロセスは以下に適応します：
- 📋 あなたの意図の明確さと複雑さ
- 🔍 既存のコードベースの状態
- 🎯 変更の範囲と影響
- ⚡ リスクと品質要件

始めましょう！
